# Morowa 17: Taśma Zerowa

Fanowska gra przeglądarkowa 3D (analog horror, VHS). Three.js + Vite. Grafika, dźwięk i głos generowane proceduralnie.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # statyczny build w dist/
```

Sterowanie: klik na obiekty w scenie, klawisze 1–5 kamery, PPM / Spacja (trzymaj) wizjer, kółko zoom, `M` wybór odcinka.
